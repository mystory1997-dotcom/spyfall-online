# SPYFALL ONLINE

ต้นแบบเกม Spyfall Online แบบ Multiplayer ใช้ Node.js + Express + Socket.IO โดยใช้ภาพหน้าแรกที่เลือกไว้เป็นหน้าเข้าเกมจริง

## สิ่งที่ทำงานในโค้ดชุดนี้

- หน้าแรกใช้ภาพต้นแบบ Spyfall Online ที่มีปุ่มสร้างห้อง/เข้าร่วมห้องอยู่ในภาพ และวางพื้นที่กดทับตำแหน่งปุ่มให้กดได้
- สร้างห้องได้ 3–8 คน ตั้งชื่อห้อง จำนวนผู้เล่น และเวลาพูดคุย 3/5/7/10 นาที
- รหัสผ่านห้องไม่บังคับ: ถ้าเว้นว่าง ห้องเป็นสาธารณะ และหน้าเข้าร่วมจะไม่แสดงช่องรหัสผ่าน
- ถ้าตั้งรหัสผ่าน ห้องเป็นส่วนตัว หน้าเข้าร่วมจะแสดงช่องรหัสผ่านหลังตรวจสอบห้องเท่านั้น
- สร้างรหัสห้องแบบสุ่มและคัดลอกได้
- แจกสถานที่/บทบาทเฉพาะผู้เล่นแต่ละคน สายลับไม่เห็นสถานที่
- ช่วงพูดคุยจับเวลาจากเซิร์ฟเวอร์
- สายลับเดาสถานที่ได้หนึ่งครั้ง ถ้าถูกชนะทันที ถ้าผิดฝ่ายผู้เล่นทั่วไปชนะ
- โหวตคนละหนึ่งเสียง ซ่อนผลจนจบ และจบก่อนเวลาเมื่อผู้เล่นที่ออนไลน์ลงคะแนนครบ
- กติกา Plurality: ผู้ได้คะแนนสูงสุดถูกจับ หากเสมอหรือไม่มีผู้ลงคะแนน สายลับชนะ
- แสดงผลสถานที่ สายลับ บทบาท ผลโหวต และคะแนนสะสม
- ผู้เล่นเข้ากลางรอบได้ แต่จะเริ่มมีบทบาทในรอบถัดไป
- เปลี่ยนเจ้าของห้องเมื่อ Host หลุด และรองรับกลับเข้าห้องด้วย player token
- หากผู้เล่นที่ยังอยู่ในรอบเหลือน้อยกว่า 3 คน รอบจะถูกยกเลิกโดยไม่คิดคะแนน

## วิธีเปิดทดสอบในเครื่อง

ต้องติดตั้ง Node.js 20 ขึ้นไป จากนั้นเปิด Terminal ในโฟลเดอร์นี้ แล้วรัน:

```bash
npm install
npm start
```

เปิด `http://localhost:3000`

การทดสอบหลายเครื่องในเครือข่ายเดียวกัน ให้เปิดพอร์ต 3000 และให้เครื่องอื่นเข้าผ่าน IP ภายในของเครื่องที่รันเซิร์ฟเวอร์

## วิธีเปิดออนไลน์ให้เพื่อนต่างเครือข่ายเข้าเล่น

โปรเจกต์นี้มีทั้ง Client และ Server แล้ว แต่ยังไม่ได้ถูกนำขึ้นโฮสต์สาธารณะ จึงยังไม่สามารถสร้างห้องข้ามอินเทอร์เน็ตได้จนกว่าจะ Deploy:

1. นำโฟลเดอร์นี้ขึ้น GitHub repository
2. สร้าง Web Service บน Render / Railway / VPS ที่รองรับ Node.js และ WebSocket
3. Build command: `npm install`
4. Start command: `npm start`
5. ตั้ง Environment Variable `NODE_ENV=production` (ถ้าต้องการ)
6. เปิด URL HTTPS ที่ผู้ให้บริการออกให้ แล้วแชร์ URL ให้ผู้เล่นทุกคน

เซิร์ฟเวอร์ใช้ `process.env.PORT` และ Socket.IO รองรับ WebSocket; ไม่ต้องกำหนดพอร์ตตายตัว

## กติกาคะแนนในรุ่นนี้ (ค่าเริ่มต้นที่ยังปรับได้)

- ฝ่ายผู้เล่นทั่วไปชนะจากการจับ Spy ถูก: ผู้เล่นทั่วไปที่อยู่ในรอบ +2 คะแนน
- ผู้ที่โหวต Spy ถูก: โบนัสเพิ่ม +1 คะแนน
- Spy ชนะจากการไม่ถูกจับ / โหวตผิด / เสมอ / ไม่มีคนลงคะแนน: +2 คะแนน
- Spy เดาสถานที่ถูก: +3 คะแนน
- Spy ถูกจับหรือเดาสถานที่ผิด: 0 คะแนน

คะแนนชุดนี้เป็นค่าที่ใส่ไว้เพื่อให้ระบบทดสอบได้ ไม่ใช่ข้อสรุปที่ผู้เล่นยืนยันแล้ว

## ข้อจำกัดที่ควรรู้ก่อนเปิดใช้งานจริง

- ข้อมูลห้องเก็บในหน่วยความจำของเซิร์ฟเวอร์ หากรีสตาร์ตเซิร์ฟเวอร์ ห้องและคะแนนในห้องจะหาย
- ระบบนี้เป็น MVP สำหรับทดสอบเกม ยังไม่มีบัญชีผู้ใช้ถาวร ฐานข้อมูล ระบบรายงาน/แบน และระบบป้องกันการโจมตีระดับ production
- การกลับเข้าห้องใช้ token ที่เก็บใน localStorage ของอุปกรณ์เดิม ควรเพิ่มระบบจัดการบัญชีและการหมดอายุ token ก่อนเปิดบริการเชิงพาณิชย์
- เสียงพูดคุยยังไม่ได้รวมในแอป ผู้เล่นใช้การพูดคุยภายนอกเกมระหว่างทดสอบ
- การตรวจสอบโค้ด JavaScript ด้วย `node --check` ผ่าน แต่สภาพแวดล้อมสร้างไฟล์นี้ติดตั้ง dependency จาก npm ไม่สำเร็จภายในเวลาที่กำหนด จึงยังไม่ได้รันทดสอบ end-to-end บนเซิร์ฟเวอร์จริง
